# Como adicionar screenshots dos projetos

1. Coloque aqui os arquivos de imagem (.png, .jpg, .webp)
   Sugestão de nomes:
   - servicedesk.png
   - financeiro.png
   - laboratorio.png
   - habitos.png

2. No arquivo src/data/translations.js, em cada projeto adicione:
   image: "/images/nome-do-arquivo.png"

3. Recomendação: imagens de 1280x720 ou 800x500 pixels
